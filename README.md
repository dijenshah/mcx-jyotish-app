# MCX જ્યોતિષ રિસર્ચ એપ – રિલીઝ હોસ્ટિંગ

આ રિપોઝીટરી ફક્ત **એપના APK રિલીઝ અને અપડેટ માહિતી (`update_manifest.json`)** માટે છે. સોર્સ કોડ અહીં નથી.

- એપ: MCX સોના/ચાંદી × હિન્દુ જ્યોતિષ (સંશોધન માટે, રોકાણ સલાહ નથી)
- **પહેલી વાર ઇન્સ્ટોલ:** [Releases](../../releases/latest) માંથી તમારા ફોન માટે `app-arm64-v8a-release.apk` ડાઉનલોડ કરી ઇન્સ્ટોલ કરો.
- **આગળના અપડેટ:** એપમાં સેટિંગ્સ → અપડેટ તપાસો (અથવા ઓટો) – એપ પોતે નવું વર્ઝન ડાઉનલોડ કરી ઇન્સ્ટોલ કરાવશે.
- `update_manifest.json` – એપ આ ફાઇલ વાંચી નવું વર્ઝન શોધે છે.

નવું વર્ઝન બહાર પાડવાના પગલાં: [RELEASING.md](RELEASING.md)
